# Changelog

## v1.0.0

- First release
- Pins for all four soulstone fragments (Hellfire, Netherstorm, Blade's Edge, Shadowmoon), plus a second Hellfire spot
- Pins on the Outland continent map
- Collected fragments hide automatically; all pins hide after the quest is turned in
- Right-click a pin to set a map waypoint
- Options: icon scale, icon alpha, warlock-only, hide collected, show after completion, continent pins
